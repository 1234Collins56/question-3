GROUP 3: PERSONAL HOMEPAGE

FILES
- index.html: homepage with proper document structure, metadata and four sections.
- style.css: external stylesheet.
- favicon.svg: icon displayed in the browser tab.

HOW TO RUN
1. Extract this ZIP file.
2. Open the folder.
3. Double-click index.html to open it in a browser.
4. Look at the browser tab to see the favicon.

PERSONALIZE BEFORE SUBMISSION
- Replace every instance of "Your Name" with your actual name.
- Update the author metadata.
- Edit the About Me, Interests and Goals text so it accurately describes you.
- Optional: change the letters YN in favicon.svg to your initials.

REQUIREMENTS CHECK
- DOCTYPE, html, head and body elements: included.
- Title, description, keywords and author metadata: included.
- At least three sections with headings and formatted text: four included.
- Favicon linked in the head: included.
- Comments explaining major code sections: included.
